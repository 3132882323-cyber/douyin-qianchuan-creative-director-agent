# 产品价值与优化审计

更新日期：2026-09-01

## 产品主任务

本项目的核心不是提供尽可能多的素材工具，而是帮助千川编导完成一条可审查的创意迭代闭环：

历史数据或已有转写 → 找到问题 → 生成一版可拍任务 → 跟踪制作与上线 → 回填结果 → 人工判断下一轮。

不直接服务这条闭环的能力，应降为按需工具或维护功能，不能和每日主操作争夺注意力。

## 当前功能价值分层

以下结论是基于现有流程、操作成本、重复程度和失败面进行的定性审计。项目不采集用户行为数据，因此不把该判断伪装成真实使用率统计。

| 层级 | 数量 | 功能组 | 产品决定 |
| --- | ---: | --- | --- |
| 核心高价值 | 8 | 创作任务、报表导入、素材复盘、可拍方案、实验版本、人工制作状态、结果与决策、转写分析到可拍草稿交接 | 保留并继续缩短路径 |
| 必要支撑 | 4 | 多项目、恢复/备份/更新、行动台与引导、自有母版匹配 | 保留，但降低视觉权重 |
| 低频专业 | 2 | 人工图片局部修复、从原片开始的本机视频处理 | 保留在折叠区或独立工作台 |
| 已完成收敛 | 2 | 侧边栏与独立工作台重复的转码流程、并列暴露过多导出格式 | 已合并实现并采用渐进展开 |
| 待合并或删除 | 1 | 只打开来源链接的独立按钮 | 继续观察，暂保留为明确的用户触发边界 |

本轮以 17 组能力为审计基线：12 组直接有明确价值，2 组只适合低频专业场景；原 3 组收敛候选中已有 2 组完成，剩余 1 组继续观察。这里的“待删除”不代表立刻砍掉：必须先确认没有独有数据或参数，再提供替代入口。

## 主要问题

### 1. 信息架构

- 侧边栏素材页仍同时承载母版匹配、图片修复、更新、备份和隐私说明，工具与维护职责仍有混杂；重复转码实现已经移出。
- 方案页同时包含生成、版本台账、制作状态、结果和人工决策，单卡信息密度偏高。
- 独立工作台的视频路线需要 FFmpeg、PowerShell、路径和结果文件，操作成本显著高于直接分析已有转写，但此前两条入口视觉权重相同。

### 2. 稳定性

- `sidepanel.js` 仍超过 3,300 行，`workbench.js` 超过 1,300 行，修改一个流程时容易影响相邻能力。
- 工作台正文、分析和草稿仍只存在于页面内存；意外刷新会丢失，虽然界面已诚实提示，但恢复能力仍不足。
- 文件读取、结果导入和交接包含异步过程；没有操作代际保护时，旧任务可能在重置或新任务之后完成。
- 浏览器扩展真实窄宽、长文本、连续切换与失败恢复仍依赖人工验收。

### 3. 功能有效性

- 规则型结构分析适合做缺项提醒和分段标注，不应被描述为智能创意判断或投放预测。
- 本机转码的价值是统一格式和提取音频，不是去水印；重复实现现已合并到独立工作台。
- JSON、CSV、Markdown 等专业格式现已收进“更多导出”；日常复制与交接仍保持直接可见。
- 来源链接按钮只打开原页，不产生分析价值，适合并入来源备注的次级操作。

## 分阶段优化

### P0：立即实施

- 将“分析已有转写”作为推荐快速路径；选中后暂时收起视频和 FFmpeg 步骤，但不清空已有页面态。
- 让步骤概览、主面板和侧栏导航同步显示当前、完成、提醒或跳过。
- 为转写导入、执行结果导入和交接增加最新操作保护；重置和任务重建必须让旧异步结果失效。
- 保留所有安全边界，不增加平台读取、远程处理或自动执行能力。

### P1：下一轮

- 已完成：将侧边栏的转码能力迁移并合并到独立工作台，只保留一个任务实现；母版匹配提供上下文入口，但浏览器不会跨标签传递文件选择。
- 把更新、备份和隐私说明移入独立“维护”折叠区；素材页优先显示母版与项目资产。
- 已完成：将 JSON / CSV / Markdown 等专业导出收进“更多导出”，保留复制、发送和交接等高频动作。
- 把实验版本卡拆成摘要、制作、结果、决策四层渐进展开，默认只显示当前需要操作的一层。

### P2：需要产品确认

- 提供明确可关闭的浏览器会话草稿恢复，只保存转写正文和白名单草稿，不保存视频、文件名或本机路径；实施前必须同步隐私说明。
- 将 `sidepanel.js` 和 `workbench.js` 按项目、实验、素材、交接和维护拆分，降低回归范围。
- 增加真实 Chrome 集成验收：窄侧边栏、快速换文件、重置竞态、存储失败、超长正文和 IndexedDB 失败。

## 验收指标

- 有转写的用户在 3 次主动操作内进入结构分析。
- 任何页面只突出一个主操作；专业导出和维护按钮不与主操作同级。
- 快速换文件、重建任务或重置后，旧异步结果不能重新出现。
- 切换入口、项目或筛选时不静默清空内容。
- 核心流程失败后必须保留输入，并给出明确重试位置。
- 不增加远程代码、平台数据读取、静默上传、自动投放或隐藏标识处理。
