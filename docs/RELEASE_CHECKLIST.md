# V1.1.0 源码发布检查清单

本清单用于发布前复核。自动检查可以在源码环境完成；Chrome 人工验收、打包和 GitHub 发布必须由发布者在可信设备上完成。

## 版本与仓库

- [x] `manifest.json`、`package.json`、侧边栏、工作台、方案与转码默认版本均为 `1.1.0`。
- [x] `LICENSE`、`README.md`、`PRIVACY.md`、`CHANGELOG.md` 均包含在源码包中。
- [x] `git status` 只包含本次预期文件；没有 `.pem`、Token、Cookie、下载素材、本机绝对路径或临时日志。
- [x] 未删除或覆盖用户未提交的无关改动。

## 自动验证

```powershell
npm test
npm run check
```

- [x] Node 单元测试全部通过（150 / 150）。
- [x] 18 个 JavaScript 入口或安全模块通过 `node --check`。
- [x] `tools/transcode-worker.ps1` 通过 PowerShell AST 解析。
- [x] `git diff --check` 无空白错误。
- [x] 静态 HTML ID 唯一，所有 JavaScript 静态 ID 选择器均有对应控件。
- [x] Manifest 权限仍为 `sidePanel`、`storage`；可选主机权限只有固定 GitHub API。
- [x] CSP 精确为 `script-src 'self'; object-src 'none';`，页面没有远程脚本、模型或 WASM。
- [x] 源码不存在 `innerHTML` 写入、`eval`、动态函数或文档写入等执行入口。
- [x] CSV 公式安全、非媒体导入限额、V0.5/V0.6 恢复和损坏存储隔离测试通过。

## Chrome 人工验收

- [ ] 在全新浏览器资料目录“加载已解压”，扩展卡片显示 `1.1.0` 且无 Manifest 错误。
- [ ] 点击扩展图标可打开侧边栏；首次三步引导可收起、重新打开，并保持键盘焦点可见。
- [ ] 在约 280–400 px 窄侧边栏检查四个标签页、恢复提示、引导、表格横向滚动和按钮布局。
- [ ] 导入 `examples/sample-report.csv`，完成字段映射、复盘、生成、编辑、复制和三种导出。
- [ ] 取消文件选择器、导入错误 CSV / JSON 后，当前成功报表、复盘和方案保持不变。
- [ ] 人工构造单个损坏存储键后重新打开：页面仍可用、面板列出具体键、取消清理不变、确认后只删除列出的键。
- [ ] 使用 V0.5 schema 1 与 V0.6 schema 2 备份分别导入，确认迁移提示与内容正确。
- [ ] 未授权、无 Mask、清空 Mask、重置修复、PNG 透明通道和 JPEG 质量流程符合界面说明。
- [ ] 工作台与侧边栏的文件数量、单文件、总量和非媒体文件上限错误信息清晰。
- [ ] 在 1920px、1440px、1024px、720px、480px 和 280px 宽度检查工作台：页面无横向滚动，顶部导航、任务概览和唯一下一步按钮可用。
- [ ] 逐步验证顶部唯一主操作：选素材、补校验、生成任务、导出清单、导入结果、导入转写、分析、交接；每次点击只执行当前一步。
- [ ] 首屏不预选入口；选择“处理本地视频”后主操作打开视频选择，选择“分析已有转写”后主操作打开文本导入，辅助入口可聚焦粘贴区。
- [ ] 在已有视频任务、转写正文和分析结果时来回切换入口，确认内容不被清空，提示列出保留内容，真实完成状态不倒退。
- [ ] 分别在仅选入口、已填路径、已选视频、任务待导出、转写任务待导出、已有正文、分析待导出、交接失败和交接完成状态点击“开始新一轮 / 重置本轮”；确认按钮始终可见且保持辅助视觉层级。
- [ ] 重置确认文案准确列出尚未导出的处理/转写任务和未导出或未成功发送的分析；点击取消后逐项确认文件、字段、正文、结果、进度和错误完全不变。
- [ ] 确认重置后所有文件 input、入口单选、路径和授权参数、任务区、正文、分析结果、状态、进度与错误回到初始态；原文件、侧边栏工作区、`chrome.storage.local` 和既有 session 收件箱结果保持不变，焦点回到首个入口。
- [ ] 处理失败、结果导入失败、交接失败与收件箱冲突时，顶部状态和重试入口准确，原任务、转写或分析结果不丢失。
- [ ] 在浏览器 200% 缩放下检查长路径、PowerShell 命令、任务队列与分析结果不遮挡按钮。
- [ ] 工作台导出交接包后，侧边栏先预览、仅确认填入空白字段；清除未应用预览可重导，成功应用后同会话拒绝重复应用。
- [ ] 工作台点击“发送并打开编导台”：空槽入队并显示预览；同一分析重复发送幂等；已有不同结果时不覆盖，先提示处理旧结果。
- [ ] 已有不同 JSON 或会话预览时，新 session 结果只显示“另有待确认结果”；主动切换后才替换预览，应用或明确清除后才消费。
- [ ] 模拟 `sidePanel.open()` 不可用或拒绝：交接仍在 session 收件箱，工作台明确提示点击扩展图标；备用 JSON 仍可导出和导入。
- [ ] 构造损坏、未知字段、超限和超过两小时的 session envelope，确认失败关闭、清理且创作任务不变。
- [ ] 用错误 schema、错误来源、未知字段、超长值、本机路径、活动内容和篡改 ID 的交接包逐项确认失败关闭，原任务不变。
- [ ] 分别导入 SRT、VTT、TXT 与 MD，确认分析片段显示正确的时间/段落来源；编辑正文后旧映射立即失效并提示。
- [ ] 未选择改进建议时不能生成草稿；选择建议后只生成一个主要测试变量，修改草稿后旧确认立即取消。
- [ ] 检查草稿的测试编号、父版本、匿名来源分析、11 个可编辑字段、证据引用、JSON 与 Markdown 导出。
- [ ] 未明确确认时不能发送或导出 V2 交接；确认后同包幂等、异包冲突、过期与 JSON 备用流程保持正确。
- [ ] 侧边栏完整只读显示 V2 草稿，确认它不覆盖已有创作任务字段或 `creativePlan`；V1 交接继续兼容。
- [ ] 页内下一步、最近任务、标签分页与分析结果跳转后，实际焦点目标处于可见区域；开启“减少动态效果”时不平滑滚动。
- [ ] 所有清空/重置确认在“取消”后保持原状态，在“确认”后仅清理当前会话目标。
- [ ] 默认不访问 GitHub；主动检查时才申请可选权限，拒绝权限后不发起版本请求。
- [ ] DevTools Console 无未处理 Promise 拒绝、CSP 报错或运行时异常。

## 安全与产品边界人工复核

- [ ] 没有页面读取、内容脚本、平台请求拦截、链接视频解析/下载或远程转写。
- [ ] 没有暗水印、隐藏指纹、版权/溯源标识检测、定位、移除或规避功能。
- [ ] 图片修复只修改用户人工 Mask 与向内羽化范围，原图不覆盖。
- [ ] PowerShell 任务仅接受固定参数白名单；输入、输出和可执行路径仍经过现有路径校验。
- [ ] 导出的任务清单可能包含本机路径或来源备注，文档已提醒只在可信设备保存。
- [ ] 分析交接包不包含原始转写全文、来源文件名、视频信息、本机路径或未知私有字段；V2 草稿只包含固定白名单。
