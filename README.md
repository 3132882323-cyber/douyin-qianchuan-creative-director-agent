# 抖音千川素材编导 Agent

一款专门为抖音千川素材编导打造的开源 Chrome/Edge 扩展。

它常驻浏览器侧边栏，把千川投放报表、历史素材表现和编导测试思路放到同一个工作区，帮助编导回答三个核心问题：过去什么素材有效、下一批应该拍什么、怎样控制变量验证创意方向。

> 不是通用文案生成器，而是面向抖音电商素材生产流程的编导助手。

## 适合谁

- 抖音电商素材编导
- 千川投手和素材负责人
- 信息流短视频编导
- 商家自营内容团队
- 需要建立素材生产与复盘标准的品牌团队

## 当前能力

### 千川报表分析

- 导入千川 CSV 报表并自动识别常用字段
- 按“高消耗且达标、起量但不达标、低曝光待验证”划分素材
- 汇总人群、钩子、卖点和场景表现
- 同时关注消耗门槛与 ROI，避免把低曝光素材误判为创意失败

### 创意测试规划

- 从表现较好的素材中提取基线方向
- 自动生成下一轮测试矩阵
- 每轮只改变一个关键变量，例如钩子、卖点、场景或人群
- 支持导出 JSON 和 Markdown，方便继续整理编导任务

### 自有母版匹配

- 将平台素材与商家自有原片进行本地文件指纹匹配
- 区分“指纹完全一致、名称与大小候选、仅名称候选、未找到”
- 所有文件只在本地浏览器处理，不上传素材内容

## 标准使用流程

```text
导入千川报表
→ 找出达标跑量素材
→ 提取人群/钩子/卖点/场景
→ 确定下一轮唯一测试变量
→ 生成素材测试矩阵
→ 交给编导继续完成脚本与分镜
→ 上线后回填结果
```

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录。
6. 点击扩展图标，在浏览器侧边栏中打开工作台。

扩展使用 Manifest V3，需要 Chrome 114+ 或对应版本的 Chromium Edge。

## 产品优化路线

### P0：让编导真正每天可用

- 增加产品 Brief：人群、痛点、卖点、证据、促销和制作条件
- 从素材策略直接生成口播、分镜和拍摄任务单
- 增加服饰、美妆、食品、家清等类目策略模板
- 支持测试矩阵一键复制和表格导出

### P1：让历史数据指导创作

- 素材标签批量编辑与自动聚类
- 人群 × 钩子 × 卖点 × 场景交叉分析
- 素材疲劳和生命周期判断
- 对新素材提出“保留什么、只改什么”的迭代建议

### P2：形成团队素材资产

- 项目、品牌和产品素材库
- 编导、投手、剪辑之间的审核流程
- 脚本与分镜版本记录
- 投放结果回填和创意经验沉淀

产品的北极星指标不是“生成了多少脚本”，而是：**上线素材中达到目标消耗且 ROI 达标的素材占比。**

## 隐私与产品边界

- 报表和素材默认只在本地浏览器处理。
- 不读取千川账号密码，不拦截平台网络请求。
- 不提供暗水印移除、破解、定位、搬运或平台风控规避。
- 需要干净素材时，应回到商家自有原片、工程文件和已授权素材重新制作。

详细说明见 [PRIVACY.md](PRIVACY.md)。
